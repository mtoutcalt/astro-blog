# Minimal Astro App

A stripped-down Astro application with just the essentials.

## Commands

| Command       | Action                           |
| :------------ | :------------------------------- |
| `npm install` | Installs dependencies            |
| `npm run dev` | Starts local dev server          |
| `npm run build` | Build production site            |
| `npm run preview` | Preview build locally          |
